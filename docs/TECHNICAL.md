# 기술 설명

원본 16 MiB ROM을 32 MiB로 확장하고 데이터와 Thumb 훅을 배치합니다. 한글당 한 코드와 원래 8픽셀 셀을 유지합니다. 폰트 컨테이너 16/17/18을 재배치합니다.

0x08025790 줄 추출에서 번역 후 복사하며, 0x28FD20 테이블의 메뉴 문자열도 재배치해 둘째 줄이 원문을 참조하는 문제를 해결합니다.

CT 타일·팔레트·맵, AN 프레임, 중첩 Pf/BPE를 원래 구조에 맞춰 구성합니다. 엔딩은 0x7D9D38 테이블의 24/25번을 교체합니다. 원본 크기 256×160, 별과 영문 픽셀은 유지합니다.

주요 구현: tools/build.py, gfx_ko.py, native_graphics_ko.py. 검사: utest.py, audit_runtime.py.
